# Vektralogos — Промпти для NotebookLM-ресёрчу

## Валідація ніші (конкуренти)
Порахуй частоту скарги "експорт у розмитий/растровий PNG замість вектора"
серед 1-зіркових відгуків Customily і Zepto окремо. Дай: (1) % відгуків з
цією скаргою від загальної кількості 1★, (2) 3 показові цитати-приклади,
(3) чи згадують юзери кирилицю/шрифти як частину проблеми.

## Бібліотеки серверного вектору
Порівняй resvg, fontkit, Ghostscript-CMYK-конверсію за: (1) підтримка
text-to-outlines для кирилиці, (2) відповідність PDF/X з ICC (FOGRA39/SWOP),
(3) активність підтримки (дата останнього релізу). Зведена таблиця +
рекомендація на кожен крок pipeline.
