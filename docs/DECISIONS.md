# Журнал рішень (ADR-lite)

Формат: дата · рішення · чому · альтернатива.

---

- **2026-07-31 · Назва проєкту — Vektralogos.** Бренд для друкарського-вектор
  Shopify-app. Перевірку домену/ТМ винести на Gemini/Claude AI.

- **2026-07-31 · Ніша — Shopify Print-Ready Personalizer.** Стійка до
  каннібалізації платформою, реальний WTP, дистрибуція через App Store, нульова
  юр. відповідальність. Альтернативи (SPR-recovery, скидки, GDPR) відкинуто на
  гейті каннібалізації / liability.

- **2026-07-31 · Сервер — тільки Python.** Одна мова крізь усі фази (LangGraph
  теж Python), менше рухомих частин. Альтернатива Node+Python гібрид — відкинуто
  як зайву складність для навчального проєкту.

- **2026-07-31 · Друкарський файл — вектор, не растр.** `resvg` лише для прев'ю-
  мініатюр. Print-PDF будуємо як справжній вектор.

- **2026-07-31 · Текст → криві (outlines) за замовчуванням.** Прибирає весь клас
  багів зі шрифтами/кирилицею (жалоба №1 конкурентів). Вбудовування шрифтів —
  опція.

- **2026-07-31 · CMYK/PDF-X через Ghostscript + ICC (FOGRA39/SWOP).** «Native
  CMYK» бібліотек рендеру ненадійний. ReportLab — резервний варіант.

- **2026-07-31 · Оркестрація — LangGraph, з Фази 2.** Найкращий навчальний
  інструмент для агентних графів. Claude Tool Runner / Managed Agents — у Фазі 5.

- **2026-07-31 · Модель — claude-opus-5.** Дефолт для всього коду проєкту.

- **2026-07-31 · Canvas JSON — канонічна схема = `server/schema.py`.** Реалізована
  Pydantic-модель (надмножина чернетки спеки: реєстр `fonts[]`, RGB/CMYK,
  `rect`, `dpi`, `background`, `image`+`is_photo_zone`). Спеку Фази 0 приведено
  у відповідність. Альтернатива — перейменувати код під мінімальну чернетку —
  відкинуто: код реальний, у тестах, і enforce'ить інваріанти в типах.

- **2026-07-31 · LLM-контракт — гібрид `prompt → DesignBrief → Canvas JSON`.**
  LLM (claude-opus-5) віддає семантичний DesignBrief; детермінований
  шаблонизатор (`server/templater.py`) розкладає його у Canvas JSON із
  координатами. Причина: LLM слабкий у міліметрових координатах; тракт
  лишається end-to-end (ціль §1 спеки). Альтернативи: «prompt→CanvasJSON
  напряму» (крихкі позиції) і «тільки DesignBrief» (немає end-to-end) —
  відкинуто.

- **2026-07-31 · Print-тракт без SVG-файлу.** `JSON → text-to-outlines
  (fonttools) → vector PDF (ReportLab) → Ghostscript CMYK`, без проміжного SVG.
  Прибирає ризик, що SVG→PDF-конвертер розтеризує/зіпсує кирилицю. SVG — лише
  клієнтське прев'ю (Fabric.js).

- **2026-07-31 · Шрифт Фази 0 — Noto Sans (OFL).** Повне покриття укр.
  кирилиці (ґ/ї/є/і); bundled у `server/fonts/`. Той самий .ttf для клієнта й
  сервера (інваріант §1).

- **2026-07-31 · Preflight-функція і FOGRA39 ICC — відкладено в кінець Фази 0.**
  Рішення Антона. `cmyk.py` уже підтримує ICC через `PRINT_ICC_PROFILE`; сам
  профіль і preflight `{ok, issues}` додамо перед мерджем.

- **2026-07-31 · Фаза 1 — preflight-агент, детермінована ReAct-петля без LLM.**
  Вибір fix-інструмента — 1:1 маппінг за `issue.code` (allowlist `FIXABLE_CODES`),
  без генеративного кроку: друкарський фікс не віддають моделі на «вгадування».
  ReAct-досвід з LLM свідомо винесено у support-бот (RAG) і наступні фази.
  Деталі й відповіді на відкриті питання спеки —
  `docs/specs/VEKTRALOGOS_Phase1_Plan-and-Decisions_v1.0_2026-07-31.md`.

- **2026-07-31 · `element_index` — структуроване поле в `PreflightIssue`.** Агент
  бере індекс елемента з поля, не парсить регексом з людського `message`.
  Публічний `{ok, issues}` лише розширено (`to_dict` дає `element_index`),
  зворотньо сумісно. Альтернатива (парсинг рядків) — відкинуто як тех-борг.

- **2026-07-31 · Петля не рендерить PDF щоітерації.** Усі виправні коди
  (bleed/out_of_media/low_dpi) — рівня спеки; `preflight(spec)` без PDF їх ловить.
  Ghostscript-рендер — рівно один раз, у фіналі (RGB/PDF-X перевірки). Петля
  тестується без gs, швидша. Альтернатива (рендер щокроку зі спеки §4) —
  відкинуто як зайвий і крихкий (gs може падати).

- **2026-07-31 · Зупинка агента — фікспойнт + масштабований запобіжник.**
  Первинна умова — «набір issue перестав зменшуватись» (конфлікт → `no_progress`);
  сирий `max_iterations` — жорсткий cap `max(8, 3·N)`, не головний критерій.
  Статуси: `ok` / `needs_human` (лишився error, §5) / `no_progress` /
  `max_iterations_reached`. `no_pdfx_intent` (config-warn) статус НЕ псує.

- **2026-07-31 · overlap-check і support-бот — відкладено (рішення Антона).**
  Overlap для `shrink_photo_zone` → Фаза 2 (потрібна модель розкладки; усадка до
  якоря нових накладань не створює). Support-бот на RAG → окрема гілка
  `feat/p1-support-bot` ПІСЛЯ мержу preflight-агента (код не спільний, PR малі).

- **2026-07-31 · FOGRA39 ICC — підключено (ISO Coated v2, ECI).** Профіль
  `ISOcoated_v2_eci.icc` (характеризація FOGRA39) з офіційного пакета ECI
  (`eci_offset_2009.zip`). `render()` тепер дає PDF/X-3 з OutputIntent на цьому
  профілі. Бінарник НЕ в репо (тримаємо без важких асетів) — `make fetch-icc`
  качає локально, шлях у `.env` (`PRINT_ICC_PROFILE`), `server/icc/*.icc`
  в `.gitignore`. Потрібен gs-флаг `--permit-file-read` (dSAFER блокує читання
  ICC із PDFX_def.ps). Preflight `{ok, issues}` — усе ще відкладено.

- **2026-07-31 · Фаза 5 (фінал) — LangGraph vs Claude Managed Agents (порівняльний ADR).**
  Ф5a перенесла Ф1 support-бота на CMA й прогнала живе порівняння (5 контрольних
  питань, один прогін ≈$0.63, підтверджено Антоном; teardown виконано й
  перевірено — 0 активних агентів/env/сесій). Результат:

  | Вимір | Самописна петля (Ф1–Ф4, LangGraph) | Claude Managed Agents (CMA) |
  |---|---|---|
  | Хто хостить цикл + інструменти | **Ми** (пишемо й хостимо) | **Anthropic** (ми лише Agent-конфіг) |
  | Retrieval у support-QA | наш BM25 top-5 (`rank_bm25`) | агент сам: grep/read/glob по репо |
  | Якість відповідей (5 питань) | усі 5 коректні, з цитатами, коротші (~0.8–1.5K зн) | усі 5 коректні, з цитатами, багатші (~1.4–2.7K зн, +механізм) |
  | Out-of-corpus («Zepto») | чесно «немає в доці» ✅ | чесно «немає в доці» ✅ |
  | Латентність | секунди (1 LLM-виклик + локальний BM25) | хвилини (провіжн контейнера + clone + агентні tool-виклики) |
  | Вартість | ~1 виклик claude-opus-5, локальний пошук | $0.08/session-hour + більше токенів (агентні кроки) ≈$0.63/прогін |
  | Спостережність | наш JSON-трейс (Ф4a) | Console-трейс + event-стрім CMA |
  | Контроль (гейти/бюджети) | повний, наш (approval-гейт/token-budget Ф4) | керований платформою |
  | Гігієна ресурсів | локально, нічого не тарифікується | **треба явний teardown** (archive/delete), інакше тарифікується |

  **Висновок (коли що):** самописна LangGraph-петля лишається для друкарського
  тракту (потрібні наш `render()`+Ghostscript і детерміновані гейти Ф4) і для
  дешевих частих запитів; CMA — коли треба хостинг циклу+пісочниці «з коробки»,
  розклад (scheduled deployments), або пісочниця з інструментами, яку ми не
  хочемо тримати самі. Для support-QA обидва дають коректний, доко-обґрунтований
  результат — вибір диктує не якість, а хто хостить, вартість і латентність.
  **`versioned agent config сам не тарифікується — гроші йдуть за сесії` (§3
  спеки).** SDK: `anthropic` 0.75→0.120.2 (CMA); Ф0–Ф4 не зачеплені (90/90).
  Деталі — `docs/specs/VEKTRALOGOS_SPEC_Phase5-ManagedAgents_v1.0_2026-07-31.md`,
  `server/managed_support.py`.

- **2026-07-31 · Ф5b — Ops-агент: host-side custom tools + cron (код без live).**
  Друкарський тракт (preflight/render) потребує нашого коду+Ghostscript, яких
  немає в cloud-пісочниці CMA → віддаємо їх агенту як host-side custom tools
  (CMA Pattern 9): агент кличе `run_preflight`/`render_pdf`, наш `dispatch_custom_tool`
  виконує `preflight_agent_graph`/`render` у нас і повертає результат — переюз
  Ф2/Ф0 без переписування під пісочницю. `deployments.create` (cron, дефолт пн
  06:00) — автономний ops-каданс. **Live НЕ запускали** (рішення Антона: код без
  live; cron тарифікується безстроково — потрібен окремий «go» + план вимкнення).
  `teardown_deployment` (pause→archive) обов'язковий. `server/managed_ops.py`,
  10 офлайн-тестів. Цим Фаза 5 і вся навчальна програма STRATEGY §3 завершені.
