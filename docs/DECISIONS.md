# Журнал рішень (ADR-lite)

Формат: дата · рішення · чому · альтернатива.

---

- **2026-07-31 · Назва проєкту — Vektralogos.** Бренд для друкарського-вектор
  Shopify-app. Перевірку домену/ТМ винести на Gemini/Claude AI.

- **2026-07-31 · Ніша — Shopify Print-Ready Personalizer.** Стійка до
  каннібалізації платформою, реальний WTP, дистрибуція через App Store, нульова
  юр. відповідальність. Альтернативи (SPR-recovery, скидки, GDPR) відкинуто на
  гейті каннібалізації / liability.

- **2026-07-31 · Сервер — тільки Python.** Одна мова крізь усі фази (LangGraph
  теж Python), менше рухомих частин. Альтернатива Node+Python гібрид — відкинуто
  як зайву складність для навчального проєкту.

- **2026-07-31 · Друкарський файл — вектор, не растр.** `resvg` лише для прев'ю-
  мініатюр. Print-PDF будуємо як справжній вектор.

- **2026-07-31 · Текст → криві (outlines) за замовчуванням.** Прибирає весь клас
  багів зі шрифтами/кирилицею (жалоба №1 конкурентів). Вбудовування шрифтів —
  опція.

- **2026-07-31 · CMYK/PDF-X через Ghostscript + ICC (FOGRA39/SWOP).** «Native
  CMYK» бібліотек рендеру ненадійний. ReportLab — резервний варіант.

- **2026-07-31 · Оркестрація — LangGraph, з Фази 2.** Найкращий навчальний
  інструмент для агентних графів. Claude Tool Runner / Managed Agents — у Фазі 5.

- **2026-07-31 · Модель — claude-opus-5.** Дефолт для всього коду проєкту.
