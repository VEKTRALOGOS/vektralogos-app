# Vektralogos — Операційна модель (3 AI + людина)

## Ролі та єдине джерело правди

| Хто | Роль | Де живе | Пише в |
|---|---|---|---|
| **Claude Code** | Розробка, код, архітектура, тести | Git-репо (**SoT — джерело правди**) | код + `docs/` у репо |
| **Claude AI** (чат/Project) | Стратегія, промпт-інжиніринг, копірайт, спеки | claude.ai Project | тексти → ти вставляєш у репо |
| **Gemini** (+ NotebookLM) | Дослідження з грундингом, конкурентка, факти | NotebookLM notebook | ресёрч → `docs/research/*.md` |
| **Ти (Антон)** | Рішення, гейти, тестування, підтвердження відправок | усюди | вирішуєш розвилки |

**Правило:** канонічним є **репо**. Усе, що народжується в Claude AI чи Gemini,
має осісти файлом у репо (`docs/…`), інакше воно «не існує» для проєкту.

## Потік роботи (handoff)

```
Gemini/NotebookLM ──ресёрч──> docs/research/*.md ──┐
                                                   ▼
Claude AI ──промпти/спеки/копі──> docs/specs/*.md, docs/prompts/*.md
                                                   ▼
Claude Code ──код по спеці──> гілка feat/* ──> ти рев'юїш ──> merge
                                                   ▼
рішення фіксуються в docs/DECISIONS.md
```

## Конвенції

- **Гілки:** `feat/<name>`, `fix/<name>`, `chore/<name>`, `docs/<name>`.
- **Фази:** тег у назві гілки/PR — `feat/p0-pdf-pipeline`, `feat/p2-product-graph`.
- **Рішення:** кожне архітектурне рішення — рядок у `docs/DECISIONS.md`
  (дата · рішення · чому · альтернатива). ADR-lite.
- **Ресёрч:** кожен ресёрч від Gemini — окремий `docs/research/<тема>.md` з датою
  й джерелами. Не в чаті — файлом.

## Каденція

- Один спринт = одна Фаза (P0…P5 з STRATEGY.md).
- Початок фази: Claude AI пише спеку → Claude Code реалізує → ти рев'юїш.
- Ресёрч (Gemini) паралельно, не блокує код по low-regret речах.
