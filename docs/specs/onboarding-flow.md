## Мета флоу

Від install до першого готового print-ready файлу — без втручання людини,
з мінімумом кроків. Кожен крок або будує довіру до вектора/CMYK, або підштовхує
до платного тарифу — нічого зайвого.

## Кроки

| # | Екран | Дія користувача | Що показуємо | Ціль кроку |
|---|---|---|---|---|
| 1 | Install success | — | Free-тариф активовано автоматично (10 exp/міс), без картки | Нульовий бар'єр входу |
| 2 | Welcome | Клік "Створити перший дизайн" | 1 речення: «Клієнти дизайнять — ви отримуєте CMYK PDF, готовий до друку» | Одразу озвучити differentiator |
| 3 | Sample product picker | Обрати шаблон (футболка/гравіювання/табличка) | 3 preset-шаблони з кирилицею в прикладі | Показати кирилицю з коробки одразу |
| 4 | Editor (Fabric.js) | Змінити текст/колір у прев'ю | Live-прев'ю в браузері | Дати відчути швидкість без серверного рендеру |
| 5 | Export | Клік "Отримати print-ready файл" | Спінер з написом стадії: "Конвертація в CMYK…" → "Перевірка DPI…" | Зробити preflight видимим, не чорною скринькою |
| 6 | Result | — | Прев'ю PDF + бейджі: ✅ CMYK ✅ 300 DPI ✅ Текст у кривих ✅ Вильоти | Довіра через прозорість перевірки |
| 7 | Post-export nudge | — | Лічильник "9 з 10 безкоштовних експортів залишилось цього місяця" | М'який upsell-тригер, не блокуючий |

## [!IMPORTANT] Логіка ліміту (Free → Starter)

- Лічильник експортів показувати з **першого** експорту (не ховати до вичерпання).
- На 8/10 — banner (не modal): "Starter від $19/міс — 75 експортів". Не блокує роботу.
- На 10/10 — hard stop на новий експорт, editor лишається доступним (не втрачати
  контекст дизайну), CTA на upgrade прямо в місці блокування.
- Overage ($0.30/exp) на Free-тарифі **не пропонувати** — тільки апгрейд на
  Starter/Growth. Overage доступний лише на платних тарифах (логіка з ADR
  pricing).

## Що НЕ входить у v1.0 (свідомо відкладено)

- Email-послідовність after install — Sales/Support Agent, Фаза 3.
- A/B тестування welcome-копірайту — Фаза 4 (evals).
- In-app чат підтримки — RAG support-бот, Фаза 1, окрема гілка.

## Метрики для Director Agent (Фаза 3, зв'язок зі STRATEGY.md §4)

- % install → перший export (activation rate)
- % досягли 8/10 → upgrade click
- Час від install до першого export (ціль: <3 хв)

## Залежності для розробника

- Крок 5 (спінер стадій) вимагає, щоб pipeline повертав проміжні статуси
  (`converting_cmyk`, `checking_dpi`, `done`) — не єдиний блокуючий виклик.
  Якщо `feat/pdf-pipeline` цього не вміє зараз — завести issue, не хардкодити
  фейковий таймер на фронті.
