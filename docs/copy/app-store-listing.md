## Key benefits (3× ~30 слів, обов'язковий блок Shopify)

**[!IMPORTANT] Benefit 1 — Справжній вектор, не растр**
Клієнти дизайнять — ви отримуєте CMYK PDF з вбудованими шрифтами й кирилицею в кривих. Жодних мильних PNG, які ламають друк і псують репутацію майстерні.

**[!IMPORTANT] Benefit 2 — Preflight-перевірка вбудована**
Кожен дизайн автоматично проходить перевірку DPI, вильотів і кольорового профілю перед тим, як потрапити до вас. Брак на друці — це минуле.

**[!IMPORTANT] Benefit 3 — Нуль ручної роботи на файлах**
Клієнт бачить прев'ю в браузері, ви отримуєте готовий до друку файл на пошту/у замовлення. Жодного «поправ у Corel перед друком».

## Detailed description (розгорнутий блок)

Vektralogos — застосунок кастомізації товарів для магазинів, що друкують: мерч,
гравіювання, таблички, упаковка.

**Проблема, яку ми вирішуємо.** Стандартні особисто-конструктори (Customily,
Zepto та інші) на виході віддають растр — PNG, який доводиться вручну
перевіряти й переробляти перед друком. Це найчастіша скарга в відгуках
конкурентів.

**Як працює Vektralogos.**
1. Клієнт створює дизайн у вбудованому редакторі — прев'ю миттєве, у браузері.
2. Сервер збирає справжній друкарський файл: текст переведено в криві, кольори
   сконвертовано в CMYK за ICC-профілем (FOGRA39/SWOP), вильоти й DPI перевірені.
3. Ви отримуєте PDF, готовий до друку без жодної ручної правки.

**Кому підходить.** Магазини мерчу, гравіювальні майстерні, друкарні на
Shopify, які втомилися перевіряти й переробляти файли клієнтів вручну.

**Кирилиця з коробки.** Текст переводиться в криві на етапі збірки — жодних
«поїхавших» шрифтів і кракозябрів при друку.

## Feature list (буліти для сторінки)

- Друкарський вектор на виході: SVG → PDF, CMYK, 300 DPI
- Текст → криві за замовчуванням (кирилиця без збоїв)
- Автоматичний preflight: DPI / вильоти / кольоропрофіль
- Прев'ю в браузері (Fabric.js) — швидко, без навантаження на сервер
- Вбудований білінг через Shopify (жодних сторонніх платіжних форм)

## FAQ (для сторінки застосунку)

**Чи підтримується кирилиця?**
Так, текст конвертується в криві — шрифт не «злітає» при друку незалежно від
мови.

**Який формат файлу я отримую?**
PDF у CMYK з ICC-профілем (FOGRA39/SWOP), вильотами й вбудованими шрифтами —
готовий здати в друк без правок.

**Чи потрібен окремий графічний редактор для перевірки файлів?**
Ні — preflight вбудований і виконується автоматично перед тим, як файл
потрапляє до вас.
