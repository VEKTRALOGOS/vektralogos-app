## Технічні нотатки для зйомки

- **Формат:** App Store вимагає портретні/ландшафтні кадри під конкретні
  роздільності — фінальні розміри уточнити з TASKS #6 (Gemini: App Store вимоги 2026).
- **Стадії експорту швидкі** (реальний gs ~1 c) — свідомо НЕ додаємо фейкових
  затримок (ґардрейл спеки, рядок 49-52). Для GIF стадії видно природно; якщо
  для стилу потрібен довший показ — це рішення монтажу запису, не хардкод у тракті.
- **Кирилиця** — ключовий диференціатор; у кадрі 2 має бути читабельною.
- Джерело правди статусу зйомки — `docs/TASKS.md` (#5).
